# Herdr delegation

The user explicitly requests proactive Herdr delegation for every substantive task when Pi is running inside Herdr. Treat this standing request as explicit authorization; the user does not need to mention Herdr in each prompt.

- Start helper agents early whenever work can be split into independent investigation, implementation, review, or verification.
- Default to two or three helper agents when parallel work would materially improve speed or confidence.
- Keep the primary agent responsible for coordination, integration, verification, and the final answer.
- Prefer read-only helpers. Use one writer unless agents own clearly disjoint files.
- Create sibling panes in the current tab and working directory while preserving the user's focus.
- Work without delegation only for trivial questions and tiny mechanical edits.
